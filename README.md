# Sticky Notes (for DataArt)

A single-page web application for sticky notes built with Vite, React and TypeScript.

## Features

- Create a notes by double-clicking on the board
- Move notes by dragging
- Resize notes by dragging the bottom-right corner
- Delete notes by dragging them to the trash zone
- Edit note text by double-clicking on a note
- Notes are saved to localStorage and restored on page load
- Notes are created with random colors

## Pending features

- Notes are created with a fixed size, BUT you could modify it later with mouse resizing
- Saving notes to REST API

## Requirements

- Node.js 18+
- npm 9+

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The output will be in the `dist` folder.

## Browser support

Latest versions of Google Chrome, Mozilla Firefox and Microsoft Edge.
